# 朝学習 英単語・英熟語・中学英語テストアプリ

システム英単語（全2,032問）とターゲット英熟語1000（`00_英熟語テスト出題計画_2学期.xlsx` の「熟語別出題」シート）、
中学英語の復習（全1,357問）からランダムに100問を出題し、意味を3択（ア・イ・ウ）から選ぶテストアプリです。

## 機能

- **英単語モード / 英熟語モード / 中学英語モード**：ホーム上部でワンタップ切り替え。英単語はエメラルド×アンバー、英熟語は紫×ピンク、
  中学英語はオレンジのテーマ。テスト・練習・復習・ランキングはどのモードも同じ仕様で、記録はモードごとに別々に保存
- **習得（覚えた）判定**：問題ごとに習熟ポイント（0〜6）を持ち、6点で「覚えた」。正解でテスト +3／練習 +2／復習 +1.5、
  不正解（練習の時間切れ含む）で0点に戻して要復習。本番テストで時間内に出題されなかった問題は対象外。
  ホームに「全◯問のうち何％覚えたか」を表示
- **アカウントと個人用URL**：番号は 101〜135、201〜235、301〜335 の105アカウント（以前の1〜35番は301〜335番に移した）
  - 一人ひとりに個人用URL（`/u/<合言葉>`）を配る。開くとその端末がそのアカウントでログインし（Cookie に保存）、次からはホームを開くだけで続きができる
  - 個人用URLで開いていない端末は、どの画面も「個人用のURLから開いてください」と表示するだけで、記録を見たり書いたりできない。
    API も毎回 Cookie の合言葉から番号を確かめ、送られてきた番号は使わない（ほかの人の番号では記録できない）
  - はじめて開いたときにニックネームを登録する
  - 合言葉そのものはリポジトリに置かず、`lib/accounts.ts` には SHA-256 のハッシュだけを置く。URLの一覧（CSV）は管理者が保管する
- **ホーム**（`/`）：各コーナーの進捗の概要をカードで表示（マイページで表示するコーナーだけ）。カードを押すとそのコーナーのページ（`/c/word`・`/c/study`・`/c/materials` など）へ。
  コーナーのページ上部の切り替えでも、ほかのコーナーへ移れる
- **みんなの学習**（`/friends`）：登録している人の一覧（自分の組を先に表示）。押すとその人のページ（`/friends/番号`）で、各コーナーの進捗の概要と、
  取り組んでいる教材（科目・書名・区分・進捗）・過去問の大学と科目が見られる
- **マイページ**（`/mypage`）：ニックネームの変更、ホーム・ランキングに表示するコーナーの選択、みんなに見せないもの（コーナー単位）の選択。
  見せないコーナーは、友達のページに出さず（API も本人以外には返さない）、英単語・英熟語・中学英語はランキング、学習時間はランキングとみんなの目標からも外す
- **テスト**：1000問からランダム100問。複数の意味がある熟語（①②…）は朝学習と同じく1つの語義を正解として出題
  - 制限時間は2分30秒のカウントダウン。0になると自動で採点（未回答は不正解）
  - 選択肢を押すとすぐ次の問題へ。答え合わせは最後にまとめて表示
  - 結果画面で「不正解だけ」「全問」を切り替えて確認できる
- **練習モード**：1000問を番号順に50問ずつ20セクションに分割
  - セクションの単語一覧（意味を隠すモードあり）。単語をタップすると発音と例文（和訳つき）を表示
  - セクションごとのテストは50問からランダム15問、1問5秒のカウントダウン。1問ごとに正誤を表示し「次へ」で進む。12点（8割）以上で ○、満点で ◎
  - セクションマップで未完成のセクションがひと目でわかる
  - 練習モード専用ランキング（クリア数 → ◎の数 → 合計点）。全員の20セクションの進み具合をマスで表示
- **練習モードのセクション数**：英熟語は20セクション、英単語は41セクション（最後は32問）、
  中学英語は27セクション（元データの Level 1〜27 に対応。Level 28 の7問は練習テスト15問を作れないのでセクション27にまとめ、最後は57問）
- **復習コーナー**：要復習の問題からランダム15問。開始前に残り数とルールを表示。1問ごとに◯✕で答え合わせ。
  4回連続正解（1.5点×4）で「覚えた」になり卒業（ランキングには含めない）
- **サウンド**：英熟語の発音（ブラウザの読み上げ機能）、やさしいBGM、正解・不正解の効果音。ヘッダーのボタンでそれぞれオン／オフ
- **学習時間コーナー**：ホーム上部の切り替えで「英単語／英熟語／学習時間」の3つから選ぶ、独立したコーナー（テーマは水色）。1日ごとの学習時間（5分単位）と振り返り（😊😐😣の絵文字で選ぶ）を記録。
  日ごとに、その日に学習するもの（予定。登録している学習教材・過去問の大学と科目・「塾・予備校」から選ぶ。1日10個まで）と目標時間を設定できる。予定と目標（日・週）・週のゴールは過去の日も、約2か月先までの日も立てられる（学習時間と振り返りは当日まで）。今日の予定と目標時間はホームの学習時間カードにも出る
  1週間は月曜〜日曜で、週の合計・記録した日数を表示。週ごとに目標時間を設定でき（設定しない週は前の目標を引き継ぐ）、達成率を表示。
  週ごとに定量ゴール・定性ゴール（それぞれ30字まで）を書ける。定性ゴールの文は本人だけが見られる。
  週の最後の日（日曜日）からは、定量・定性ゴールそれぞれを ◎〇△× で振り返れる（過去の週も）
- **みんなの目標**（`/study/goals`）：週ごとに、目標学習時間に対する学習時間・達成率と定量ゴールを番号順に一覧。前の週にもさかのぼれる。
  今週の分は今の時点の学習時間で、開いている間は1分ごとに自動で更新。日曜日以降と前の週は ◎〇△× の振り返りも表示（定性は記号だけ）
  英単語・英熟語のモードとは関係なく1人1つの記録。学習時間のコーナーではヘッダーの「練習」「復習」を隠す
- **学習時間ランキング**（ランキングページの「⏱️ 学習時間」コーナー。英単語・英熟語と並ぶ独立したコーナー）：毎日の学習時間ランキング（日付を選べる）／毎週の学習時間ランキング（週を選べる・目標の達成率つき）
- **学習教材のコーナー**（ホームの「📒 教材」）：学習教材シート（Excel）と同じ項目（科目・書名・区分・単位・全体の量・今いる周・
  現在位置・目標周回・完了期限）を1冊ずつ登録（1人20冊まで）。現在位置は＋／−ボタンでも変えられ、「次の周へ」で周を1つ進めて現在位置を0にする。
  残りの量・期限までの週数・1週間／1日のペース・全体の進捗・状態は、Excel のシートと同じ計算で自動表示
- **学習教材の進捗の書き出し**（管理者ページ）：登録している全員分を、学習教材シートと同じ見た目の Excel（1人1シート・シート名は番号）に書き出す。
  ひな形は `public/templates/materials-template.xlsx`（元のシートから「はじめに」と生徒用シート1枚を残し、入力欄を空にしたもの）。
  入力欄（A〜I列）に値だけを入れるので、色・▼の一覧・条件付き書式・計算式・ロックはひな形のまま
- **過去問のコーナー**（ホームの「📝 過去問」）：過去問演習シート（Excel）と同じ項目で、大学・学部ごとに科目（4つまで）を登録（1人10校まで）。
  科目ごとに満点・目標得点率・完了期限と、年度ごとの得点を入れる。年度は最初に最新の5年度分があり、自分で20件まで追加・削除・選び直しができる（予定年分＝登録した年度の数）。
  済・残り・最新／平均／最高の得点率・目標との差・1週間に必要な年数と、全科目の得点がそろった年度の合計得点率を、Excel のシートと同じ計算で表示
- **過去問の記録の書き出し**（管理者ページ）：過去問演習シートと同じ見た目の Excel（1人1シート）に書き出す。ひな形は `public/templates/pastexams-template.xlsx`。
  Excel の年度の列は10年分なので、見出しをその人のいちばん新しい年度から10年分に書き換え、それより古い年度は書き出さない（件数を画面に表示）
- **各アカウントの状況**（管理者ページ）：全アカウントの最後の記録日・各コーナーの進み具合（覚えた割合・テスト回数・今週の学習時間・教材・過去問）と「見せない」設定を一覧で表示。番台で絞り込み、未登録のアカウントも表示できる。今週と先週の学習時間も並べて見られる。行を押すと、その人の様子をタブで詳しく見られる（見せない設定のコーナーも表示）：学習時間は週ごとの合計・目標・達成率・曜日ごとの時間と気分・ゴールの振り返り（過去の週もさかのぼれる）、学習教材は1冊ずつの進捗・今いるところ・期限とペース・状態、過去問は大学ごとの試験日までの日数・合計の得点率と科目ごとの進み具合・得点率・年度ごとの得点
- **📕 日本史コーナー**（`/c/jhist`）：日本史一問一答3,051問。英単語などの仕組み（習熟ポイント・3択）は使わず、記録は `jhist_` で始まる専用のテーブルに保存する
  - 節別の練習（`/jhist/practice`）：節ごとの157セクション（10〜30問。一覧は `data/jhist/sections.md`）。一覧は空欄に正解を入れた文で、「答えを隠す」で赤シートのように隠せる。
    4択テストはランダム15問（セクションが15問未満なら全問）・1問20秒。正答率80％以上で ○、満点で ◎。答えるたびに正文・別解・取り違え注意を表示
  - 回答はサーバーで採点し直し、回答ログ（365日で自動削除）・問題ごとの正答数と選ばれた誤答の数・取り違えた組を保存する
  - 今日の学習（`/jhist/today`）：用語（2,197語）ごとに記憶の段階（0〜6）と次の出題日を持つ間隔反復。段階で形式が変わる（0・1＝4択、2＝正誤判定、3〜6＝記述。記述はマイページで「自己採点」か「入力して採点」を選べる）。
    正解すると段階が上がり、次の出題は当日中・1・3・7・14・30・60日後。不正解は段階が下がり、段階3までは同じセッションの7問後に違う問題文で出し直す。
    4択・正誤で15秒以上かかった正解は「迷った正解」（段階を上げず翌日に）、記述の△も翌日に。段階4以上が「定着」。数は `lib/jhist/constants.ts` で調整できる
  - 今日のノルマ：新出は「未学習の対象用語 ÷ 入試30日前までの残り日数」（1日10〜40語、入試30日前からは0）、復習は期限の来た用語。重要度は S から始め、S の段階2以上が80％を超えたら A、早慶上智なら A も80％を超えたら B を加える。
    復習（期限切れの多い順）を先に時代をまたいでシャッフル、新出は節の順。1セッション20問。ノルマを達成した日を連続日数として数える
  - 入試日・目標（日東駒専・GMARCH＝重要度S＋A／早慶上智＝S＋A＋B）は初回に選び、マイページで変えられる。記述の答え方・入試形式の難易度の初期値も目標に合わせる（日東駒専・GMARCH＝自己採点・基本、早慶上智＝入力して採点・発展）
  - 節別の練習は新しい用語の「導入」：段階0の用語に正解すると段階1へ（上の段階は上げない。不正解なら下げる）
  - 実力テスト（`/jhist/test`）：ランダム50問（同じ用語は1問）・4択・12分30秒。範囲は全範囲か時代（12区分）、難易度は日東駒専・GMARCH（S＋A）か早慶上智（S＋A＋B）。
    100点満点に換算。出題した問題はサーバーで覚えておき、送られた答えと照らし合わせる。ランキング（平均点）は全範囲のテストだけ。正解しても段階は上げず、不正解なら下げる（未学習の用語は未学習のまま）
  - ランキングの「📕 日本史」タブ：実力テストの平均点と、定着語数（段階4以上の用語の数）
  - ホームのカード：定着率（分母は目標の対象用語数）・今日のノルマの残り・連続日数・テストの回数・平均・最高
  - コーナーのページ：今日の学習、時代別の定着率、段階別の語数、入試までの日数と「このペースで全範囲が定着する見込み日」（直近14日の定着語数の増え方から）、節別の練習、実力テスト
  - 年代チャレンジ（`/jhist/chrono`）：年代整序の290件から、並べ替え・最も近い年の出来事（4択。正解が一意になるよう、誤答は正解より基本20年・発展5年以上離れたもの）・前後の判定（基本は4つから1つ、発展は5つからすべて）を混ぜて5問。
    1問に同じ西暦の項目は入れない。時代を選んで作れなければ隣の時代まで広げる。答え合わせで全項目の西暦を表示。記憶の段階には使わない
  - 取り違えやすい語（`/jhist/confusions`・コーナーのページに上位10組）：4択で選んだ誤答がほかの問題の正解だった組。押すとその2語の問題を続けて出す（正解しても段階は上げず、不正解なら下げる）
  - 「問題がおかしい」ボタン：答え合わせの画面と実力テストの結果に置く。問題ID・番号・自由記述（任意・100字まで）・日時を保存
  - 管理者ページの「📕 日本史（教員用）」：時代 × 生徒の定着率と今日のノルマの達成状況、正答率の低い問題（3回以上答えられたもの。よく選ばれた誤答つき）、問題の報告
  - 入試形式トレーニング（`/jhist/exam`）：1回10問。難易度（基本・発展）と範囲（学習済みの用語だけ＝段階1以上・全範囲・時代）を選ぶ。作れなければ全範囲から
    - 入力記述：漢字を入力して採点。全角・半角、前後や間の空白、「・」「＝」は無視、カタカナとひらがなは同じとみなす（読みを答える問題は除く）。漢字の異体字は別解にあるものだけ。
      1文字だけ違えば基本は△「誤字の可能性」（違う文字に印）、発展は×。サーバーでも採点し直す
    - 3文正誤：同じ時代・別の用語の3文（正しい文の数は0〜3がほぼ同じ割合）。基本は1文ずつ、発展は3文に印をつけてから答え合わせ
    - 複数選択：同じ時代の5文。基本は「正しいものを2つ」（正文はちょうど2つ）、発展は「すべて」（正文は1〜4）
    - 組合せ：同じ元問題IDで正文が同じ2問（78組）から空欄2つの文を作り、「正正・正誤・誤正・誤誤」の4択（誤答は各問題の誤答から）
    - 文・誤答はデータにあるものだけを使う。答え合わせで全文の正誤と正文を見せる。ノルマ・連続日数・ランキングには入れない。正解しても段階は上げず、誤判定した文・間違えた語の用語だけ段階を下げる
- **ランキング**（モード別）：平均点ランキング／日別最高点ランキング（日付を選んで過去の日も見られる）／練習ランキング
  - 平均点ランキングの行をタップするとその人の全受験結果を表示

## Cloudflare へのデプロイ

[OpenNext](https://opennext.js.org/cloudflare) を使って Cloudflare Workers で動かします。
記録は **Cloudflare D1**（`wrangler.jsonc` の binding `DB`）に保存します。テーブルは初回アクセス時に自動で作られます。
保存先の優先順は D1 → Upstash Redis（Vercel 版）→ ローカルファイル です。

無料プラン（1回の処理の CPU 時間は10ミリ秒まで）で記録が増えても動くよう、テストを受けるたびに
回数・合計点・最高点・最後の受験日時（summary）と日ごとの最高点・回数（days）を保存し、
ホーム・ランキング・友達のページではそれだけを読みます。テストの記録そのもの（results）は、
ランキングで人を押したときと自分の「最近の成績」で1人分だけ読みます。
この仕組みより前の記録は、最初にランキングなどを開いたときに1人1回だけ集計して保存します。
学習時間も同じ考え方で、1人分の記録全体（`study`）とは別に、週ごとの記録（`study_weeks`）と
目標・最後に記録した日（`study_meta`）を保存し、ランキング・みんなの目標・管理者の一覧では必要な週の分だけを読みます。
記録画面は本人の記録全体だけを読みます。以前の記録は、最初のアクセスで一度だけ週ごとに分けて保存します（D1）。

## データのバックアップと読み込み（管理者ページ）

`/admin` を開くと、全員の記録をファイル（JSON）にダウンロードしたり、そのファイルを読み込んだりできます。

- 初回に管理者パスワード（8文字以上）を設定する（保存先のデータベースに保存されるので、環境変数は不要）
  - パスワードは PBKDF2（5,000回）のハッシュで保存する。Cloudflare の無料プランは1回の処理の CPU 時間が10ミリ秒までなので、
    以前の10万回（約15〜20ミリ秒）では止められていた。以前の形式で保存されたパスワードは、一度確認できたときに今の形式で保存し直す
- 読み込むと、ファイルにある番号の記録はファイルの内容で上書きされ、ファイルにない番号はそのまま残る
- Vercel 版でダウンロード → Cloudflare 版で読み込み、のように保存先の移行や定期的なバックアップに使える
- 番号を移す前（1〜35番）のバックアップファイルは、読み込むと301〜335番として入る
- パスワードを忘れたときは、D1 の Console で `DELETE FROM settings WHERE key = 'admin';` を実行してから設定し直す

1. Cloudflare のダッシュボードで **Workers & Pages → 作成 → Import a repository** から GitHub のリポジトリを選ぶ
2. ビルド設定
   - Build command：`npx opennextjs-cloudflare build`
   - Deploy command：`npx opennextjs-cloudflare deploy`
3. **Settings → Variables and Secrets** に、Upstash の接続情報を追加する（Build と Runtime の両方）
   - `KV_REST_API_URL`（例：`https://xxxx.upstash.io`）
   - `KV_REST_API_TOKEN`（種類は Secret）
4. 再デプロイすると `https://eijyukugohnd.<アカウント名>.workers.dev` で公開される

手元で Cloudflare の環境を試すときは `npm run preview`（Redis を使う場合は `.dev.vars` に上の2つを書く）。

## Vercel へのデプロイ

Vercel はファイルを保存できないため、成績データの保存に **Upstash Redis**（無料枠あり）を使います。

1. このフォルダ（`eijukugo-test-app`）を GitHub のリポジトリにアップロードする
2. [Vercel](https://vercel.com/new) で「Add New → Project」からそのリポジトリを Import し、そのまま Deploy
   （Framework は Next.js が自動選択されます）
3. Vercel のプロジェクト画面で **Storage → Create Database → Upstash（Redis）** を選んで作成し、プロジェクトに接続する
   - 接続すると環境変数 `KV_REST_API_URL` と `KV_REST_API_TOKEN` が自動で設定されます
4. **Deployments → 最新のデプロイ → Redeploy** で再デプロイすると、データが保存されるようになります

Upstash を直接使う場合は、環境変数 `UPSTASH_REDIS_REST_URL` / `UPSTASH_REDIS_REST_TOKEN` を設定しても動きます。

## データのリセット

Upstash のコンソール（Vercel の Storage 画面から開けます）の Data Browser で、次のキーを削除します。

いずれもハッシュで、フィールド名が番号です。1人分だけ消すときは各キーの該当フィールドを削除します。

- `eijukugo:users` … 登録者（番号とニックネーム）
- `eijukugo:study` … 学習時間の記録（D1 では `study` テーブル）
- 英熟語モード：`eijukugo:v2:results`（受験結果）、`eijukugo:v2:practice`（練習の最高点）、
  `eijukugo:v2:mastery`（問題ごとの習熟ポイント）、`eijukugo:v2:summary`（覚えた数・復習数・テストの集計）、`eijukugo:v2:days`（日ごとの最高点・回数）、`eijukugo:v2:wrong`（以前の復習リスト）
- 英単語モード：`eijukugo:v2:word:results`、`eijukugo:v2:word:practice`、`eijukugo:v2:word:mastery`、`eijukugo:v2:word:summary`、`eijukugo:v2:word:days`
- 中学英語モード：`eijukugo:v2:jhs:results`、`eijukugo:v2:jhs:practice`、`eijukugo:v2:jhs:mastery`、`eijukugo:v2:jhs:summary`、`eijukugo:v2:jhs:days`

Redis の接続情報は `KV_REST_API_URL` / `KV_REST_API_TOKEN`（接頭辞付きでも可）、`UPSTASH_REDIS_REST_URL` / `UPSTASH_REDIS_REST_TOKEN`、
または Upstash の接続文字列（`REDIS_URL` / `KV_URL`）から自動で読み取ります。

例文は `data/examples/01.json`〜`10.json`（熟語番号 → [英文, 和訳]）にあります。

## 問題データの更新

**日本史**：Excel（日本史一問一答_アプリ用データ.xlsx）を差し替えて、次を実行します。

```bash
node scripts/jhist-convert.mjs <Excel のパス>
```

`public/jhist/data-<ハッシュ>.json`（画面用）、`data/jhist/index.ts`・`meta.ts`（サーバー用の索引）、`data/jhist/sections.md`（セクション一覧）を作り直します。
問題ID・用語IDは Excel のものをそのまま使います（振り直さない。データを足すときは末尾に追加）。
空欄が1つでない・選択肢が重複している・年代整序の西暦が時代の範囲外 などの行があると、何も書き出さずに止まります。

`data/idioms.json` は `[{ "id": 1, "phrase": "a piece of ～", "meaning": "１つの～" }, ...]` の形式です。
意味に `①…②…` が含まれる場合、出題時に1つの語義がランダムに選ばれます。
